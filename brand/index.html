Every value on this page comes from brand/tokens.css. Change a token there and the card, this sheet and the website all follow. The buttons above preview other palettes and logos without changing any files.

Logo

The primary logo is the inline lockup: the H monogram on the left, HELIX and BIOLOGY on the right. The H's crossbar is a single DNA twist. Leave clear space around the logo at least the width of the H. Don't stretch, recolour or outline it. Use the stacked version only where the space is narrow and tall.

Colour

Each palette has five colours. Use accent for decoration only: rules, rungs and focus rings. Small text on paper uses accent-ink. npm run check tests the contrast of every palette.

Type

The brand uses two typefaces. Cormorant Garamond sets the wordmark, names and headings. Jost sets everything else.
