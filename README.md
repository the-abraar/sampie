# Helix Biology: brand & business card

Client: Samiul Alam, MBBS (DU), founder of Helix Biology (Biology, classes 9–12, Mohammadpur, Dhaka).

```sh
npm install
npm run dev      # http://localhost:4321/brand/ (brand sheet), /card/ (business card), /site/ (coming-soon page)
npm run build    # contrast check, QR, then dist/helix-card-<palette>.pdf (print) + .png (preview)
npm run check    # contrast check only
```

## Where things live

| File | What it holds |
|---|---|
| `brand/tokens.css` | **The brand.** Palettes, transparency scale, corner radii, type, spacing, buttons, logo stroke widths. Change things here. |
| `brand/logos.svg` | Logo marks: `mark-helix` (default), `mark-h`, `mark-seal`, `mark-none` (wordmark only). Coloured by tokens. |
| `brand/components.css` | Lockup, buttons, inputs, chips, surfaces for the website. Built only from tokens. |
| `brand/theme.js` | Applies `data-mark`, and `?theme=` / `?mark=` URL previews. |
| `brand/qr.svg` | Generated by the build from `SITE` in `scripts/build.mjs`. Don't edit. |
| `card/` | The card: 3.5 × 2 in, matte, 0.125 in bleed, 3/16 in safe margin. Text content is in `card/index.html`. |
| `site/` | The coming-soon page for helixbiology.sch.ac (deployed by `.github/workflows/pages.yml`). |
| `dist/` | Print-ready PDFs (2 pages: front, back) and previews, one per palette. |

## Common changes

- **Pick the final palette / logo for the card:** set `data-theme` and `data-mark` on `<html>` in `card/index.html` (and `site/index.html`). Preview first with `?theme=forest&mark=seal`.
- **Tweak a colour:** edit its theme block in `tokens.css`, then `npm run check`. It fails if text contrast drops too low.
- **New palette:** copy a `[data-theme="…"]` block in `tokens.css` and give it a name. The build picks it up automatically.
- **Softer or sharper corners:** change `--radius-button`, `--radius-card` etc. in `tokens.css`.
- **Hide the card-front watermark:** `--card-pattern-opacity: 0`.
- **Different card details:** edit `card/index.html`, then `npm run build`.

Printing: send `dist/helix-card-<palette>.pdf`. The page is 3.75 × 2.25 in with bleed, trimmed to 3.5 × 2 in. Colours are RGB; ask the printer to convert to CMYK and to show a proof first.
